# 🍕 Bella Vista Restaurant

A modern, fully responsive restaurant landing page built with **HTML, CSS and JavaScript**.

## 🌐 Live Demo

👉 **[View Live Site](https://qorqudabdullaza.github.io/restaurant-website/)**

## ✨ Features

- 📱 Fully responsive design (mobile, tablet, desktop)
- 🍝 Interactive menu tabs (Pasta / Pizza / Desserts)
- 📅 Reservation form with date/time picker
- 🖼️ Gallery section
- 🎨 Smooth scroll navigation
- ⚡ Clean, semantic HTML5
- 🎯 Modern CSS3 (Flexbox + Grid)
- 🚀 Vanilla JavaScript (no libraries)
